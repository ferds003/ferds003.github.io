This website is built using the **al-folio** Jekyll template — a clean, responsive, and academic-friendly theme. It’s tailored for personal portfolios, blogs, and project showcases and includes advanced features like:
- Collections (e.g., `news`, `projects`)
- Math and code support
- Publications integration
- Theming and social media previews
