__HOW THIS CAN BE FURTHER IMPROVED:__ Of course, if it was not obvious, the software provides the gcode for me but there are instances that the toolpath for this type of application is not definite therefore the CNC programmer should be `careful`. Like for this instance, operation is needed to be stopped midway to flip the workpiece to mill the back side of given stock! We are using the `HAAS VF2 TR` so it is not able to do that manual process despite the 5-axis capability. Operator is still expected to be involved. 

On the other hand, another thing to consider is the processor file like that of the `Haa-safe.cps` since this is needed to program the machine for the machining processes. Specific instructions on how I did this is outlined in my report but this is not applicable if done in other brands, heck even the same brand but different CNC machine! caution for the operator in the ground is needed for this
